# Texture Mapping App with Node.js
<img width="575" height="508" alt="スクリーンショット 2026-06-08 084313" src="https://github.com/user-attachments/assets/f3bd50a9-dcbd-49c0-a13d-4b6d5aaf3c42" />

HTML5 Canvasのアフィン変換機能を利用して、画面上を4回クリックして指定した四角形の領域に、画像を歪めてマッピング（テクスチャマッピング）するWebアプリケーションです。

バックエンドにはNode.jsによるシンプルな静的ファイル配信サーバーを備えており、ブラウザのローカルファイル制限（CORS）を回避してスムーズに動作させることができます。

---

## 🚀 機能特徴

* **テクスチャマッピング**: 4つの頂点をクリックすると、画像を2つの三角形に分割（クリッピング）し、それぞれに最適なアフィン変換行列を計算して描画します。
* **ピュアNode.jsサーバー**: `express` などの外部依存ライブラリを一切使用せず、Node.jsの標準モジュール（`http`, `fs`, `path`）のみで軽量な静的サーバーを構築しています。
* **モダンJavaScript**: `let` / `const` の利用や、`addEventListener` によるイベント制御など、堅牢で可読性の高いコードにリファクタリングされています。

---

## 🛠 動作環境

* Node.js v14 以上（推奨）
* モダンブラウザ（Google Chrome, Microsoft Edge, Safari, Firefoxなど）

texture-app/

├── index.html       # メイン画面（Canvas描画ロジック含む）

└── README.md        # 本ファイル
💻 使い方
1. 準備
プロジェクトのルートディレクトリに、テクスチャとして使用したい画像（JPG形式）を picture0.jpg という名前で配置してください。大きさは自由ですが、内部で一度 250x250 ピクセルにリサイズされて計算されます。

2. サーバーの起動
ターミナルまたはコマンドプロンプトを開き、プロジェクトのフォルダに移動して以下のコマンドを実行します。

Bash
node server.js
起動に成功すると、ターミナルに以下のように表示されます。

Server running at http://localhost:3000/

3. ブラウザでアクセス
ブラウザを開き、次のURLにアクセスします。
👉 http://localhost:3000

4. 操作方法
白いキャンバス内の任意の場所を 計4回 クリックします。

クリックした順に、左下、左上、右上、右下をイメージして4点を指定すると、きれいに画像がマッピングされます。

マッピングが完了すると自動的に座標がリセットされ、再び次の4点をクリックして新しい場所に描画することができます。

📐 テクニカルメモ（仕組み）
Canvasの setTransform()（アフィン変換）は平行四辺形までの変形しかサポートしていないため、一般的な四角形（3D的な透視投影など）への歪みはそのままでは表現できません。
本作品では、四角形を2つの三角形に分割し、それぞれの三角形に対して個別に変換行列（拡大・縮小・回転・傾き・移動）を計算し、clip() で切り抜いて描画することで、疑似的な自由変形を実現しています。
